# Спецификация: «Рандомный таймер сигналов»

Telegram Mini App без сервера: пользователь задаёт длительность, выбирает, какие из 5 сигналов участвуют, и сколько всего сигналов прозвучит. Приложение проигрывает их громко, в случайные моменты внутри периода. Сценарий: экран включён, телефон лежит рядом; работа при заблокированном экране — вне первой версии.

## Сигналы

Три свистка — один и тот же пронзительный судейский свисток с трелью, различаются длиной и числом; «би-бип» — жёсткий электронный двойной писк с перегрузом; «кря» — кряканье утки: гнусавое, с хрипом и падающим тоном.

Каждый сигнал — один WAV-файл целиком (44,1 кГц, моно, 16 бит), генерируется `npm run sounds` (scripts/generate-sounds.ts). Пик −1 дБ, края сглажены 5 мс; шум детерминированный, файлы воспроизводимы.

| Код         | Сигнал           | Состав                                                                                                  | Длительность, с |
| ----------- | ---------------- | ------------------------------------------------------------------------------------------------------- | --------------- |
| whistle1    | Короткий свисток | синус 2900 Гц + трель 38 Гц (тон ±3,5 %, громкость) + шум дыхания                                       | 0,2             |
| whistle2    | 2 свистка        | 2 × свисток 0,15 с, пауза 70 мс                                                                         | 0,37            |
| whistleLong | Длинный свисток  | тот же свисток, 0,8 с                                                                                   | 0,8             |
| bibeep      | Би-бип           | 2 меандра 1250 + 1330 Гц, перегруз (tanh ×5): 90 мс, пауза 50 мс, 130 мс                                | 0,27            |
| quack       | Кря              | кряканье утки: пила 310 Гц с падением до ×0,8, хрип (модуляция 55 Гц + шум), форманты 1100/2500/3500 Гц | 0,2             |
| finish      | Финиш            | пила, «сирена» 1200/800 Гц каждые 125 мс                                                                | 1,5             |

Веб-страница не может быть громче системной громкости — перед стартом приложение напоминает выкрутить громкость.

## Алгоритм расписания

`generateSchedule(settings, rng)` — чистая функция, rng передаётся снаружи.

1. Типы: если N ≥ k — каждый тип по разу + N − k равновероятно; если N < k — N разных случайных типов. Затем Фишер–Йетс.
2. F = T − t_start − t_end − Σdᵢ − (N − 1)·g.
3. N случайных точек на [0, F], сортировка → куски r₀ … r_N.
4. t₁ = t_start + r₀; tᵢ₊₁ = tᵢ + dᵢ + g + rᵢ.
5. Результат — `[{ atMs, type }]` по возрастанию.

N_max = ⌊(T − t_start − t_end + g) / (d_max + g)⌋, d_max — самый длинный из выбранных типов.
Пример: 1 мин, все типы (d_max = 0,8 с), g = 2,5 с → ⌊57,5 / 3,3⌋ = **17**. При N > N_max функция бросает `ScheduleError` с текстом «максимум N».

## Состояния

Настройки → (Старт) → Отсчёт → (5 с) → Идёт → (время вышло) → Финиш → (Повторить: новое расписание) → Отсчёт.
Идёт ⇄ Пауза (Пауза / свёрнуто ↔ Продолжить). Стоп из Отсчёт / Идёт / Пауза → Настройки. Финиш → К настройкам → Настройки.
Свернули во время отсчёта → Пауза; «Продолжить» запускает отсчёт заново.

## Экраны

- **Настройки**: длительность (±, ввод мм:сс, быстрые кнопки), 5 переключателей сигналов с кнопкой «прослушать», число сигналов с подсказкой максимума, доп. настройки (пауза, отсчёт, вспышка), напоминание про громкость, «Старт» (неактивен при ошибках), версия сборки.
- **Отсчёт**: крупные цифры, «Стоп».
- **Идёт**: оставшееся время, «Сигналов: X из N», полоса прогресса, вспышка, «Пауза» / «Стоп». Время следующего сигнала не показывается.
- **Финиш**: «Готово», журнал «мм:сс — сигнал», «Повторить», «К настройкам».

**Точность времени**: прошедшее время считается от `performance.now()`, таймер ставится до ближайшего события; пропущенные из-за задержки браузера сигналы звучат сразу, по одному разу. Пауза сдвигает оставшиеся сигналы.

**Звук через `<audio>`**, а не Web Audio: на iPhone Web Audio глушится переключателем беззвучного режима. Гипотеза, проверяется на телефонах (этап 1, TC-53). Если задан `navigator.audioSession` — `type = 'playback'`.

**Экран не гаснет**: Wake Lock API; если не работает внутри Телеграма — NoSleep.js (после согласования зависимости) или подсказка про автоблокировку.
