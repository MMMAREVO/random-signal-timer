## Деплой и подключение к боту

1. Создать репозиторий на GitHub, `git push -u origin main`.
2. Settings → Pages → Source: **GitHub Actions**. `vite.config.ts` использует `base: './'`, поэтому имя репозитория указывать не нужно. Ссылка: `https://<логин>.github.io/<репозиторий>/`.
3. @BotFather: `/newbot` → имя и username. Токен никуда не кладём.
4. BotFather → Bot Settings → Menu Button (или `/setmenubutton`) — ссылка с GitHub Pages и текст «Таймер». По желанию — Main Mini App (`https://t.me/<username>?startapp`).
5. Проверка: открыть бота на телефоне → кнопка меню → приложение на весь экран. Версия сборки видна внизу экрана настроек.
